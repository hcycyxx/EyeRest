# 远眺 · 20-20-20 护眼提醒 V1.1

适用于 Windows 10 / 11。双击 **EyeRest_v1_1.exe** 即可运行，无需安装 Python、无需管理员权限，无联网功能。

## 使用

- 启动后开始20分钟计时。到时展开悬浮窗，点击“开始远眺”，看约6米外至少20秒；倒计时结束后，自动开始下一个20分钟。
- 点击“立即休息”可随时开始20秒倒计时。
- 点击“5分钟后提醒”推迟本次提醒；点击“暂停”保留工作计时，点击“继续”恢复。休息或等待开始时点暂停，会取消本次休息，恢复后重新计时20分钟。
- **按住窗口顶部拖到屏幕左/右边缘**，移开鼠标约1秒后只留窄条；鼠标碰到窄条就展开。提醒和休息时保持展开。支持左右贴边，不含上下贴边。
- 点击“托盘”隐藏到桌面右下角；双击托盘图标重新打开。找不到时，展开托盘的隐藏图标。
- **退出：右键托盘图标 → 退出程序**。也可右键悬浮窗空白处退出。Alt+F4只收起到托盘。
- 想取消贴边：右键悬浮窗空白处或托盘图标 → 取消贴边。

## 开机启动

默认关闭。把程序放在打算长期保留的位置，再勾选“开机启动”。之后登录当前 Windows 账户时自动运行；启动时安静收起到贴边窄条或托盘。

取消勾选即可关闭。本选项仅写入当前账户的启动项 `EyeRest202020_v1`，不需要管理员权限。移动或改名后，需要在新位置重新勾选。删除程序前，先取消勾选并退出。

## 文件与设置

- `EyeRest_v1_1.exe`：独立可运行程序，可单独复制。
- `source/EyeRest.cs`：完整 C# 源码。
- `source/app.manifest`：Windows 兼容性与显示缩放设置。
- `source/build.ps1`：编译脚本；使用 Windows 自带的 .NET Framework C# 编译器，不下载依赖。
- `source/EyeRest.ico`：程序图标。

编译时，在 PowerShell 执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\source\build.ps1`。脚本发现同名 EXE 会停止，请在新的版本文件夹编译，以保留旧版本。

窗口位置及贴边方式保存于 `%LOCALAPPDATA%\EyeRest202020\v1\settings.xml`。退出后移走此设置文件，下次启动即恢复默认位置。

提醒不锁屏、不发声音；不强行中断操作，也不会自动判断你是否真的远眺。计时按实际经过时间，电脑睡眠期间仍算在内；唤醒后若已到20分钟，会在计时器恢复时提醒。多显示器按系统缩放显示，跨不同缩放屏幕后若显示大小不合适，退出后在常用屏幕重新启动。

## 简短检查范围

已允许的检查仅使用临时设置：用时间推进检查20分钟到期、5分钟稍后提醒和暂停/继续；原生窗口实际运行一次20秒倒计时，并检查贴边隐藏/展开及托盘返回。界面截图已查看，未等待真实20分钟，也未启用开机启动。鼠标靠近展开、多显示器及开机启动，仍需在你的日常环境亲自验收。

V1初版保留在相邻的 `EyeRest_v1` 目录；本目录为修订版，补全从托盘弹出的提醒结束后返回托盘的行为。
