# 远眺护眼提醒 V1.2

Windows 10 / 11，双击 EyeRest_v1_2.exe 即可运行。无需安装额外软件。

**先退出旧版**：右键桌面右下角的远眺托盘图标 → 退出程序，再双击新版。新版不会自动关闭旧版；为避免重复提醒，同一时间只允许运行一个版本。

## 时间设置

1. 点击悬浮窗“时间设置”，或右键托盘图标 → 时间设置。
2. 打开苹果手机闹钟风格的深色滚轮页。左列为提醒间隔（1–180分钟），右列为休息时长（1–300秒）。初始为20分钟、20秒。
3. 用鼠标滚轮、上下拖动数字或点击相邻数字选择。Tab切换列，方向键逐项微调，PageUp/PageDown每次10项，Home/End跳到最小/最大值。
4. 点击“完成”（或Enter）保存，并从新的间隔重新计时。若原本暂停，保存后仍保持暂停，点击“继续”再计时。
5. 点击“取消”（或Esc）放弃修改；原倒计时按实际经过时间继续。设置页打开期间暂不弹出提醒，取消后若原计时已到期则立即提醒。

休息正在倒计时时，“时间设置”暂不可用。休息结束后即可修改。设置保存后，下次启动仍会使用。设置页顶部标题可拖动。

## 日常使用

- 到提醒时间后，点击“开始远眺”，再看约6米外设定的秒数。结束后进入下一轮。
- “立即休息”随时开始设定的休息秒数。
- “5分钟后提醒”仍固定为5分钟，独立于设定的正常间隔。
- “暂停/继续”保留剩余工作时间；在等待休息或休息中暂停，会取消本次休息，恢复后使用完整间隔。
- 按住窗口顶部拖到屏幕左/右边缘，移开鼠标约1秒后只留窄条，鼠标碰到窄条就展开。提醒及休息时保持展开。
- 点击“托盘”收起；双击托盘图标展开。右键托盘 → 退出程序。Alt+F4只收起。
- 取消贴边：右键窗口空白处或托盘 → 取消贴边。

## 开机启动和本地文件

开机启动由窗口勾选框控制。把新版放到长期保留的位置再勾选；若以前启用了旧版，新版勾选后会将本工具的启动项指向新版。取消勾选即可关闭，删除前先关闭此选项。

V1.2设置保存在 `%LOCALAPPDATA%\EyeRest202020\v1_2\settings.xml`，与旧版分开保存；不读取或改写旧版时间、位置设置。只在手动开启开机启动时更新当前账户的本工具启动项，无需管理员权限。

源码在 source 文件夹。PowerShell 编译命令：`powershell -NoProfile -ExecutionPolicy Bypass -File .\source\build.ps1`。编译器使用Windows自带的.NET Framework，已有同名EXE时停止，请在新版本文件夹编译。

计时按实际经过时间，包括睡眠期间；本工具不判断你是否真的远眺。跨不同缩放屏幕后若显示大小不适合，在常用屏幕退出重启。

## 交付状态

按你的选择，本版只编译，未启动程序、未做运行测试、未改开机启动，留给你亲自试用。

建议先设为“间隔1分钟、休息5秒”，点击完成，确认提醒、倒计时和重启后的设置保存，再设为日常使用的时间。
