# 20-20-20 护眼提醒

## Platform
Windows native desktop.

## Stack
Delegated by the user's confirmation of a lightweight native Windows implementation. C# WinForms on the Windows .NET Framework; no downloaded runtime or packages.

## Users and purpose
Jack works at a computer and wants a small reminder every 20 minutes to look approximately 6 metres away for 20 seconds.

## Confirmed behavior
Chinese UI, light floating window, left/right edge hiding with hover reveal. Reminders wait for the user to start the 20-second countdown. Snooze and pause. Optional startup, off by default. Runnable executable, full source and short instructions. All V1 outputs are new files. No network access or external messages.

## Constraints
Preserve previous deliverables. Commit this version locally. Prefer light verification and let Jack perform final hands-on acceptance.
