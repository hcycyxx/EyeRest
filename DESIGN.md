# V1 desktop surface

Approved direction: a quiet light floating window, Chinese task labels, generous readable countdown and a dark green primary action. Windows desktop conventions, no web wrapper. The user pinned this narrow functional direction before implementation; it takes precedence over exploratory visual alternatives (seed:d2fec8efbb5396d1).

The window is an Operate surface: title and state, remaining time, distance and duration instruction, start/snooze actions, pause and startup, docking hint. Native YaHei UI type, ivory background #F8FAF7, ink #19352E, accent #1E5B4B. Native keyboard focus and scaled controls. Docking uses a separate 12-pixel tab within the monitor working area so it remains reachable on adjacent monitors.
